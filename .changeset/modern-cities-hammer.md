Adds the monochromeHaze look and a monochrome color mode: the glow in the box's counter-color, white on a dark box and a blue-leaning gray on a light one, read off the element's type color each frame. New ink option on attachBorealis and on paintFrame's box to set that color, and inkFor to get it for a type color. whiteHaze is unchanged.
